# 🛫 TraveloHI

**TraveloHI** is a clone of Traveloka — a travel and e-commerce web application for booking flights and accommodations. It is built with modern web technologies including **React**, **SCSS**, **Go (Fiber)**, and **PostgreSQL**.

---

## ✨ Features

- 🔍 Search and filter travel destinations
- 🏨 Browse and book hotels or accommodations
- ✈️ Simulated flight booking interface
- 💬 Responsive and interactive UI
- ⚙️ API backend using Go (Fiber) + PostgreSQL

---

## 🛠️ Tech Stack

### Frontend:
- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [SCSS](https://sass-lang.com/)

### Backend:
- [Go](https://golang.org/)
- [Fiber](https://gofiber.io/)
- [PostgreSQL](https://www.postgresql.org/)
- [GORM](https://gorm.io/) (ORM for Go)
